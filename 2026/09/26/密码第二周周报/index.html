密码第二周周报

数据类型

文本类型

str：被指定为文本类型的内容，就类似于在文本文档（.txt）里面写的东西一样

数值类型

1.int：只取数字的整数部分
2.float：将数字改写为浮点数
3.complex：将数字改写为复数

序列类型

list：列表

目前只学了这几个类型，序列类型里面的tuple和range还没学，还有映射。集合，布尔，二进制类型也都没学呢

字符串

比较少的字符串就用一对单引号或者双引号来表示，但是多行字符串可以用三对双引号或者单引号来表示
字符串也是一个数组，字符串中的空格要占一个位置，例如：
b = “Hello, World!”
print(b[2:5])
这个输出结果就是 llo
如果改写为：
b = “Hello, World!”
print(b[-3:-1])
此时输出结果就是 rld

字符串方法

使用方法：变量.方法()
len()：可以查看字符串的长度，同时它也可以查看列表，元组，字典长度
strip()：可以删除开头和结尾的空白字符，这个东西我能想到的除了在后端记录密码、用户名避免因为空格而导致登录报错之外，我不知道它还有什么用处
lower():将字符全部返回为小写
upper():与lower()相反
replace(“要被替换的字符串”，“替换为的字符串”):将字符串中的一小段替换掉
split(“寻找作为分割点的符号”):找到分隔符是将一整个字符串分割为许多子字符串

字符串组合

举个例子：
age = “18”
txt = “My name is zzy, I am “ + age
print(txt)
此时输出的是 My name is zzy, I am 18
但是，注意到，如果这句话 age = “18” 没有引号怎么办？此时再打印就会报错，因为 + 两边的数据类型需要相同，左边是str烈性，右边是int类型，文本类型不一样就不能相加，但是如果两个数字，一个是str类型，另一个是int类型，虽然文本类型不一样，但是依然不会报错
显然，按照上述的方法，我们需要时刻注意 + 两边的文本类型是不是一样的，这会消耗我们的精力，这很不健康，那么主播主播，有没有可以无脑插入字符串的方法？有的兄弟，有的有的
format()方法就此诞生，我们只要将上面的例子进行一个小小的更改：
age = “18”
txt = “My name is zzy, I am {}”
print(txt.format(age))
这里{}起到一个占位符的作用，format 就自动的将 age 这个变量插入到这个占位符里面，但是如果我有很多要插入的东西怎么办？举个例子：
quantity = 3
itemno = 567
price =114514
myorder = “I want {} pieces of item {} for {} dollars.”
print(myorder.format(quantity, itemno, price))
这样，format 就会按照顺序将变量添加到占位符里面

运算符

算术运算符

加(+) 减(-) 乘(*) 除(/) 取模(%) 幂(**) 取整除(//)

逻辑运算符

and 如果两个语句都为真，则返回 True
or 如果其中一个语句为真，则返回 True
not 反转结果，如果结果为 true，则返回 False

身份运算符

in 如果对象中存在具有指定值的序列，则返回 True
not in 如果对象中不存在具有指定值的序列，则返回 True

二进制运算符

& AND 与 如果两个位均为1，则将每个位设为 1
| OR 或 如果两位中的一位为1，则将每个位设为 1
^ XOR 异或 如果两个位中只有一位为1，则将每个位设为 1
~ NOT 非 反转所有位

if else

if

温馨提醒：缩进要对

elif

和 if 没什么区别，但是它会使整个程序简洁，如果一个程序写的全是 if ，那么电脑就会选择将所有的 if 全部跑一边，即使它已经找到满足条件的程序了，但是 elif 不一样，它一旦找到满足条件的程序，就会停止接下来的判断，因此会使整个程序效率更高

else

While循环

While语法

while 要判断条件：
判断为成立后所要执行的语句

break语句

break语句写在while语句里边，只要break被执行，那么整个while语句就会被停止

continue语句

continue语句和break相反，一个直接停止，一个是重新执行while语句

For循环

For语法

for 变量 in 要循环执行的内容：
开始循环后要执行的语句

break和continue语句

和while一样

range()函数

举个例子
for i in range(1,11，2):
print(i)
输出结果为1，3，5，7，9
注意：输出结果没有11

函数

创建并调用函数

用 def 定义函数，举个例子：
def function():
print(“Hello，Wrold”)
function()
此时输出结果为 Hello，Wrold

参数

def function(fname):
print(fname + “is a human”)
function(“zzy”)
此时，输出结果为 zzy is a human

递归

现在有这么一个分段函数：
若 x>0 则 f(x)=x+f(x-1)
若 x<=0 则 f(x)=0
我现在想知道 x 从 0到6 所有的值，该怎么写呢？
def function(x):
if x>0:
result = x + function(x-1)
print(result)
else:
result = 0
return result
function(6)
这样输出结果就是1，3，6，10，15，21
但是输出结果为什么不是21，15，10，6，3，1呢？
因为电脑在处理这个函数的时候发现 function(6) 算不出来，因为它需要 function(5)，以此类推直到 function(0) 它算出来是0，但是0不打印，此时它开始打印最新的结果，就是 function(1)=1 ，因此是这个顺序

类

这个对于我这个新手来说感觉有点难整

创建并使用类

函数创建用 def ，这里用 class
比如我现在要创建 Person 这个类：
class Person:
内容
要知道，类里面自带的有一个 init() 函数，这个函数无论在类里面写不写，它都会默认执行，它具有一定的性质，举个例子：
class Person:
def init(self, name, age):
self.name = name
self.age = age
def function(self):
print(“My name is”, self.name ,”I am”, sale.age ,)
p1 = Person(“zzy”, 18)
p2 = Person(“xxx”, 18)
p1.function()
p2.function()
这里可能会产生三个问题：

1.self是什么？为什么要写 self ？
self 是你自定义的对象的名字，也可以叫 this ，也可以叫 balabala 。这里如果不写self，后面的 self.name 电脑就不知道是什么，就会报错

2.self.name 和 self.age 中，点后面的 name ，age 是什么？
那是自定义的类型，和文本类型(str)和整数类型(int)是一个东西，但是这里的 name 和 age 是我们自定义的

3.为什么不写成 function(p1) 呢？
当然不可以写成这个样子！
(1)这个函数是写在类里面的，不能在外面单独使用
(2)这一条是显示这两个写法的本质区别，而不是不能这么写的原因，p1.function() 实际上是让 p1 自己去执行 function 这个函数，而 function(p1) 是你自己主动将 p1 传进 function() 这个工具中进行加工
但是我非要在外面单独用呢？
那调用时只用在 function() 前面加上 Person. 即 Person.function(p1) 就能正常使用了

还有要补充的对于我来说便于理解的东西，就是这个点，我们翻译为自然语言可以是“的”和“进行……操作”两个意思，还拿刚才这个示例来说：
self.name 可以理解为 self (就是指后面创建的对象，比如 p1 )的 name
p1.function() 可以理解为让 p1 自己运行 function() 这个函数
